# results/

Committed calibration artifacts. The full (unshrunk) calib object lives in
`../raw_results/` and is gitignored — regenerate via `run_sims.run_calib` on
a VM.

| File | Content |
|---|---|
| `gabon_calib.obj` | Shrunken calibration (top-50 trials via `calib.shrink(n_results=50)`). Loadable with `hpv.plot_calibration` and `calib.trial_pars_to_sim_pars(which_pars=i)`. |
| `gabon_pars.obj` | `calib.best_pars` dict — ready to pass to `make_sim(calib_pars=...)`. |
| `table1_parameter_uncertainty.csv` | Machine-readable version of [`../TABLE1.md`](../TABLE1.md). Regenerated by `python make_table1.py`. |

## Reference: current calibration

The committed calibration was run under `hpvsim==3.1.0` (1000 trials × 100
workers on zebra, 2026-08-25). Best mismatch: **2.393** (v3 uses a different
mismatch aggregation than v2, so this is not directly comparable to the v2
number of 0.875). The fit matches the target ASR (30.8) at median 29.6 and
tracks the cancers-by-age curve inside the top-50 95% prediction interval.
