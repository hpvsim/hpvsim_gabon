# results/

Committed calibration artifacts. Larger outputs (`scens_*.obj`,
`gabon_calib.obj`, `gabon_pars.obj`) are gitignored — regenerate them locally.

| File | Content |
|---|---|
| `gabon_pars_all.obj` | Top-100 parsets, ranked by mismatch. Each entry is a dict ready to pass to `make_sim(calib_pars=...)`. |
| `gabon_pars_top50.obj` | Top-50 parsets — same shape, sliced. `run_scenarios.py` reads this and takes `[:n_parsets]`. |
| `table1_parameter_uncertainty.csv` | Machine-readable version of [`TABLE1.md`](../TABLE1.md). Regenerated by `python make_table1.py`. |

## Reference: current calibration

The committed parsets come from a 2500-trial optuna run under `hpvsim==2.2.6`
with a best mismatch of 0.875. `gabon_pars_all.obj[0]` is the best fit; the
top-N are used for parameter-uncertainty scenario runs.
